# Aset statis (public/)

File di folder ini disajikan apa adanya di root situs (tanpa diproses Vite).

## Logo aplikasi

Taruh logo Anda di sini dengan nama **`logo.png`**:

```
public/logo.png
```

File ini otomatis dipakai untuk:

- **Favicon** (ikon di tab browser) — lihat `index.html`.
- **Logo di dalam aplikasi** — lewat komponen `src/components/Logo.tsx`
  (Landing, Login, sidebar Admin).

Rekomendasi: PNG persegi, latar transparan, ukuran ≥ 512×512 px.

> Sebelum file `logo.png` ditambahkan, aplikasi otomatis menampilkan ikon
> bawaan (Store) sebagai pengganti — jadi tidak akan ada gambar rusak.
